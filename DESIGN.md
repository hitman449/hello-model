# Hello Model design system

The rules every page follows. The tokens live at the top of `css/styles.css`; `tests/design.test.js` checks the ones a machine can check.

## Principles

- **Calm and friendly.** Warm off-white surfaces, one teal accent, soft rounded corners, plenty of space. Nothing should feel like a developer console.
- **One idea per screen.** Each screen has one main action (a filled teal button). Everything else is a quiet link or an outline button.
- **Mobile first.** Design for 375px wide, then add room at 768px and 1280px. No horizontal scrolling at any width.
- **Readable by anyone.** WCAG 2.1 AA in both themes. Jargon is explained where it appears (dotted underline and a tooltip).
- **Fast.** No frameworks. Fonts and scripts never block the first paint, and each page loads only the code it needs.

## Colour

| Token | Light | Dark | Used for |
|---|---|---|---|
| `--bg` | `#faf7f2` | `#161311` | Page background |
| `--surface` / `--surface-2` | `#ffffff` / `#f4efe7` | `#1f1b18` / `#29241f` | Cards / quiet fills |
| `--text` / `--muted` | `#1c1917` / `#655d57` | `#f5f1ec` / `#b5aca3` | Body text / secondary text |
| `--border` / `--border-strong` | `#ebe4da` / `#d8cfc3` | `#342e29` / `#4a423b` | Card edges / inputs |
| `--accent` | `#0f766e` | `#2dd4bf` | Main buttons, links, icons, focus ring |
| `--accent-soft` | `#e3f3ef` | `#10302b` | Selected and highlighted areas |
| `--ok`, `--warn-bg`, `--warn-border` | | | Ticks, warnings |

Use the tokens, never raw colours, so both themes keep working. All text pairs pass AA contrast; the accessibility tests check this on every page in both themes.

## Type

One family, Plus Jakarta Sans (400, 600, 700, 800), with the system font as fallback. Sizes come from the scale only:

| Token | Size | Used for |
|---|---|---|
| `--fs-xs` | 12px | Eyebrows, badges, keyboard hints |
| `--fs-sm` | 14px | Captions, sidebar, small buttons |
| `--fs-md` | 15px | Cards, secondary body text, guide text |
| `--fs-base` | 17px | Body text (16px on phones, so iOS doesn't zoom into inputs) |
| `--fs-lg` | 19px | Lead paragraphs, h3 |
| `--fs-xl` | 24px | h2 |
| `--fs-2xl` | 30px | Big numbers and icons |
| `--fs-title` | 28–38px, fluid | Page titles (h1) |
| `--fs-display` | 34–53px, fluid | The home headline |

Line height is `--lh-body` (1.65) for text and `--lh-tight` (1.2) for headings. Weights: 400 for text, 600 for labels and buttons, 700 for headings, 800 for the home headline.

**Line length.** Paragraphs in guides, lessons and model pages stop at `--measure` (58ch, about 65–70 characters). Intro paragraphs, which are set larger, stop at 640px.

## Spacing

An 8px rhythm with 4px half-steps: `--sp-1` to `--sp-8` = 4, 8, 12, 16, 24, 32, 48, 64px. Every padding, margin and gap is a multiple of 4px. Hairline offsets under 4px (1–3px) are allowed for borders and optical alignment.

Corners: `--r-sm` 8px (inputs, chips), `--r` 14px (cards), `--r-lg` 20px (big panels). Shadows: `--shadow` for cards, `--shadow-lg` for dialogs and popovers (none in dark mode).

## Icons

`js/icons.js` holds one set of original 24×24 line icons: no fill, 1.8 stroke, round caps and joins, in the same style as the sidebar. Each model type names its icon in `USE_CASES[id].icon`.

```js
HM_ICONS.svg("chat", 26)   // → <svg class="i" … aria-hidden="true">…</svg>
```

Icons are decorative (`aria-hidden`), so the text next to them must say what they mean. They take the text colour (`currentColor`); model icons are teal. To add one, draw it on the 24px grid with the same stroke and add it to `ICONS`. The tests fail if a model type points at an icon that doesn't exist. Don't use emoji as icons; they look different on every device.

## Touch and focus

- On touch screens (`pointer: coarse`), every button, chip and standalone link is at least `--tap` (44px) tall. Links inside sentences are exempt (WCAG 2.5.8).
- Every interactive element shows the teal focus ring when reached by keyboard. Never remove an outline without replacing it.
- Motion uses `--dur` (0.18s) and `--ease`, and is turned off for people who ask for reduced motion.

## Loading

- Fonts load without blocking the first paint (`rel="preload"` that switches to a stylesheet, with a `<noscript>` fallback), and only the four weights in use are requested.
- All scripts are `defer`.
- Learn pages load `js/kb-lite.js` (model names, icons and the glossary, about 5 KB, generated by the build) instead of the full knowledge base (about 70 KB).
- Content that is there at first paint is in the HTML, not added by JavaScript, so the page doesn't jump (for example, the example chips on the home page).
- Target: Lighthouse 90 or more in every category on every page.
